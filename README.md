# GTA V Map Vertex Color & Alpha Editor

Локальный браузерный редактор цветов, прозрачности и векторных слоёв для XML-файлов миникарты GTA V.

## Запуск

Запустите любой статический HTTP-сервер из каталога проекта, например:

```powershell
python -m http.server 8080
```

Откройте `http://localhost:8080`. Все библиотеки и стандартный шрифт находятся в `vendor`, поэтому интернет для работы редактора не нужен.

При открытии `index.html` через `file://` выберите папку с XML вручную. Для автоматической загрузки положите стандартные файлы `minimap_*.ydd.xml` в каталог `map` и используйте HTTP-сервер.

## Поддерживаемые файлы

- GTA V drawable dictionary XML с `VertexBuffer` и `IndexBuffer`;
- ZIP с XML-файлами;
- JSON-проекты редактора версии 7.1;
- SVG с залитыми контурами;
- TTF/OTF для текстовых слоёв.

Импорт ограничен 500 файлами, 50 МБ на файл и 200 МБ общего распакованного объёма.

## Проверка

```powershell
npm test
npm run check
npm run verify:sample
```

Тесты проверяют нарезку геометрии, идемпотентное объединение YDD, недеструктивный экспорт, сохранение режима Z и наличие локальных зависимостей. `verify:sample` сравнивает с файлами `fix.minimap_4_5.ydd.xml` и `minimap_4_5.ydd.xml` из каталога Downloads.
