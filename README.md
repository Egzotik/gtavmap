# GTA V Web Map Editor v8.0

Это браузерное приложение представляет собой специализированный 3D-редактор для кастомизации мини-карты Grand Theft Auto V (поддерживается загрузка форматов `.xml` и `.zip`)[cite: 30]. Страница предоставляет полноценный графический интерфейс для модификации игровой геометрии и цветов без необходимости использования сложных десктопных 3D-пакетов.

**Основные возможности страницы:**

* **Интерактивная 3D-визуализация:** Отображение загруженной геометрии карты на Canvas-холсте в трехмерном пространстве с возможностью вращения камеры, масштабирования, блокировки ракурса и включения вспомогательной сетки радара[cite: 30].
* **Управление цветами (Палитра RGBA):** Приложение автоматически парсит все файлы и собирает используемые цвета в удобную правую панель[cite: 30, 33]. Пользователь может искать цвета по HEX/RGB, изменять их тон и прозрачность (Alpha), инвертировать цвета, удалять участки геометрии по выбранному цвету, а также разделять слои в зависимости от их высоты по оси Z[cite: 30, 33]. Для быстрого выбора цвета с модели предусмотрен инструмент «Пипетка»[cite: 30].
* **Векторные слои и графика:** Левая панель инструментов позволяет накладывать поверх карты собственную графику[cite: 30]. Поддерживается добавление 3D-текста (с возможностью импорта пользовательских шрифтов `.ttf` и `.otf`), загрузка кастомных SVG-иконок и создание базовых фигур (квадраты, круги, треугольники)[cite: 30]. У каждого элемента можно гибко настроить цвет, размер, поворот, качество контуров и добавить внешнюю обводку[cite: 30]. 
* **Умный экспорт в игру:** При скачивании готового ZIP-архива приложение автоматически "нарезает" всю добавленную векторную графику по стандартной сетке игровых тайлов GTA V и генерирует правильные математические границы отсечения (Bounding Box/Sphere), чтобы объекты корректно отображались в движке[cite: 30, 32].
* **Система проектов:** Текущий прогресс работы со всеми загруженными шрифтами, текстами, иконками и настроенной палитрой можно сохранить в единый JSON-файл, чтобы в будущем продолжить работу ровно с того же места[cite: 30].
